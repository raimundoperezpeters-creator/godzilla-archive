Godzilla Archive v6.7 — respaldo completo y preparación Android PWA.

Instalación: publica todos los archivos de esta carpeta en la misma dirección HTTPS (por ejemplo GitHub Pages). Abre la URL en Chrome para Android y elige Instalar aplicación / Añadir a pantalla principal. Abrir index.html directamente desde el explorador de archivos NO instala una PWA.

Migración: en Mi diario > EXPORTAR TODO, descarga el JSON que ahora incluye imágenes personales. En el teléfono: Mi diario > IMPORTAR RESPALDO. Verifica tus datos antes de eliminar el original.

Las fotografías remotas requieren conexión. No se incluyen en el JSON. Las fotos manuales se guardan en IndexedDB.

Precaución: el almacenamiento del navegador depende de la dirección (origen). Cambiar URL o borrar datos de la app puede requerir restaurar el respaldo.
